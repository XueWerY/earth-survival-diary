## 图片拖拽改为手动 mousedown/mousemove/mouseup 实现
- **原因**：CSS `resize: both` 在 v-html 渲染的 inline-block 上跨浏览器兼容性差，无法触发拖拽
- **新方案**：
  - mousedown 在 `.md-resize-img` 上时启动拖拽，记录起始 X 和 wrapper 引用
  - document mousemove：实时计算 `wrapperWidth + delta` → 百分比，设置 `wrapper.style.width`
  - document mouseup：持久化百分比到 source `{w:N}`，重新渲染
  - `.md-resize-img` CSS：`cursor: ew-resize`；img 加 `pointer-events: none` 避免事件干扰
  - 移除旧的 `handleContainerMousedown` / `handleBlocksMouseUp`，合并为 `handleBlocksMouseDown`
- 版本号：`2026.7.23-26`
