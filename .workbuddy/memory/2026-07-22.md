# 2026-07-22

## 修复笔记编辑器光标跳动问题
- 问题：笔记块内编辑时点击文本中间，光标总被拽到末尾。
- 根因：MarkdownEditor.vue 中 textarea 的 click 冒泡到 `.md-block`（`@click.stop="activateBlock"`），activateBlock 无条件将 selection 重置到末尾。
- 修复：activateBlock 入口加守卫 `if (activeBlockId.value === id) return`，已编辑块不重复激活（3 行改动，块管理逻辑未动）。
- 版本：2026.7.22-1；已同步 CHANGELOG.md 与 public/使用指南.html。
- 备注：项目存在大量存量 vue-tsc 类型报错（App.vue、NotesPage.vue 等），与本次改动无关，未处理。

## 编辑器新增「+」按钮新建块功能
- 需求确认：用户选择「悬停块显示 + 按钮」触发，插入到该块下方（AskUserQuestion 澄清后实施）。
- 实现：MarkdownEditor.vue 3 处——.md-block 内加 button.md-block-add（@click.stop）、insertBlockBelow(id) 用 splice 插入并激活、按钮样式 left:-14px 借容器 padding 显示。
- 关键细节：按钮是块的 DOM 子元素，hover 沿 DOM 树传递不中断；left:-14px 在容器 16px padding 内不产生横向滚动；插入空块不 emit，与 addEmptyBlock 一致。
- 版本：2026.7.22-2；已同步 CHANGELOG.md 与 public/使用指南.html。

## 块失焦自动删除空块
- 需求确认：用户选择「块失焦时删除」时机（AskUserQuestion 澄清后实施）。
- 实现：仅改 deactivateBlock——失焦时若该块 source.trim() 为空则 splice 删除，再 emitFullMd（7 行新增）。
- 兼容：点工具栏/点 + 时 blur 先删空块再走原新建逻辑，无残留；全部删完显示既有占位 UI。
- 版本：2026.7.22-3；已同步 CHANGELOG.md 与 public/使用指南.html。

## 修复点击工具栏退出编辑态
- 问题：编辑中点工具栏 → mousedown 使 textarea blur → deactivateBlock 置空 activeBlockId 并销毁 textarea → handleToolbar 找不到激活块而新建块，格式插不进原文。
- 修复：工具栏容器加 `@mousedown.prevent`（1 行），阻止焦点转移，保留焦点与选区；click 正常触发插入。
- 要点：这是富文本/编辑器工具栏的标准模式——凡需保持编辑态焦点的工具按钮，一律 mousedown.prevent，而不是改 blur 逻辑。
- 版本：2026.7.22-4；已同步 CHANGELOG.md 与 public/使用指南.html。

## 工具栏无编辑块时未激活
- 需求：笔记编辑器中如果没有任何块处于编辑态，则工具栏处于未激活状态。
- 实现（MarkdownEditor.vue，3 处）：
  1. 工具栏 button 加 `:disabled="activeBlockId === null"`，activeBlockId 为 null 时所有按钮禁用。
  2. 新增 CSS `.md-toolbar-btn:disabled`（opacity 0.35 + not-allowed + 灰字），hover 也保持灰色。
  3. 简化 handleToolbar：移除「无激活块则新建块并插入」分支（现按钮禁用后不可达），仅保留 `if (targetId === null) return` 类型守卫后调用 insertIntoBlock。
- 验证：vue-tsc 无 MarkdownEditor 报错；vite build 通过（exit 0）。
- 版本：2026.7.22-5；已同步 CHANGELOG.md 与 public/使用指南.html。
